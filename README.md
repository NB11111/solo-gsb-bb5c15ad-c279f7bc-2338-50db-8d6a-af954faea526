# 纪录片字幕校订 · 本地对齐工具

供纪录片剪辑使用的**本地运行**网页：上传带时码的旧版 SRT 与逐行修订台词后，
按顺序做**全局文本对齐**，自动处理「一条拆两条」「两条并一条」，
对齐不确定或产生倒序、重叠的行会标记为「待处理」；可在页面中修改配对与时码，
确认后预览并下载新的 SRT。

- 后端：Node.js + Express（零第三方运行时依赖，仅 express）
- 前端：原生 HTML / CSS / JavaScript
- 全部处理在本机完成，不上传任何外部服务

## 单条启动命令

```bash
docker compose up -d --build
```

启动后浏览器访问：

**http://localhost:3000**

停止：

```bash
docker compose down
```

> 依赖安装在镜像构建阶段完成，容器启动即拉起服务，无额外初始化步骤或数据库。

## 必要配置

| 配置 | 位置 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 宿主机端口 | `docker-compose.yml` 中 `ports` 左侧 | `3000` | 如 3000 被占用，改成 `"8080:3000"` 即可 |
| 容器端口 | 环境变量 `PORT` | `3000` | 一般不需要改；改后需同步 `ports` 右侧与 `EXPOSE` |
| 监听地址 | 环境变量 `HOST` | `0.0.0.0` | 容器内保持默认 |

不用 Docker 时（需要本机有 Node.js ≥ 20）：

```bash
npm install
npm start        # 同样访问 http://localhost:3000
PORT=8080 npm start
```

## 使用流程

1. 左侧粘贴（或选择文件上传）**旧版带时码 SRT**。
2. 右侧粘贴（或选择文件上传）**逐行修订台词**，一行一条；粘贴 SRT 文本也可自动提取台词。
3. 点击 **开始全局对齐**。
4. 在结果表中检查「待处理」行，可直接：
   - 修改**配对旧序号**（从 1 开始）：
     - 填一个序号 = 一对一；
     - 相邻两行填**同一个**旧序号 = **一条拆两条**（可拆成更多条）；
     - 一行填 `12,13` 多个序号 = **两条并一条**（可合并多条）；
     - **留空** = 修订新增、旧稿中没有的台词。
   - 修改**开始/结束时码**（`HH:MM:SS,mmm`，逗号或点均可）与**台词文本**。
   - 删除行、末尾新增行。
5. 点击 **应用配对修改**（重算受影响分组的时间与标记），或 **按配对重排时码**
   （忽略手动时码，按当前配对重新分配全部时间）。
6. 点击 **预览并下载 SRT**，在弹窗中检查全文后下载 `revised.srt`。

## 对齐规则

- **全局顺序对齐**：以「旧 cue 序列 × 修订行序列」做动态规划（允许
  一对一、一对二拆分、二对一合并、单边跳过），最大化全片文本相似度，
  因此**重复台词会结合前后文自动定位**到正确的旧条目，而不是只取最近的一处。
- 相似度采用中文友好的 bigram Dice + 单字 Jaccard 平均；标点与空白差异
  （如新增逗号、换行）不影响匹配。
- **合并**沿用被合并旧条目的**覆盖时段**：最早开始时间 ~ 最晚结束时间。
- **拆分**在旧条目时段内按各行修订文字的字数比例分配，保证边界单调不回退。
- **新增行**在前后相邻配对的时间间隙内按时长比例插值；间隙不足或缺少锚点时
  会给默认时长并标记待处理。
- 以下情况标记 **待处理**（黄/红徽标，鼠标悬停可见原因）：
  - 相似度过低，对齐不确定；
  - 新增行 / 未被使用的旧行（旧行列在表底参考区，不导出）；
  - 同一旧序号被多个配对组使用；
  - 成片行之间出现**时码倒序或重叠**；
  - 时码无法解析或结束早于开始。

### API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/align` | 入参 `{oldSrt, newText}`，返回旧 cue、对齐行（含类型/时码/待处理原因）与未匹配旧行 |
| POST | `/api/refine` | 入参 `{oldSrt, rows, recomputeAll}`，按用户修改的配对/文字/时码重算 |
| POST | `/api/export` | 入参 `{rows}`，返回标准 SRT 文本 |
| GET | `/api/health` | 健康检查 |
